# 🥛 शिवकृपा दूध संकलन ग्रुप | Smart Milk Collection & Billing System

स्मार्ट दूध संकलन, दैनिक नोंदवही आणि स्वयंचलित बिलिंग प्रणाली (Smart Milk Collection, Daily Register & Automated Billing System).

---

## ✨ वैशिष्ट्ये (Key Features)

- **दैनिक दूध संकलन नोंदवही (Daily Collection Register):**
  - सकाळ (Morning) व दुपार (Afternoon) चे दूध प्रमाण थेट व पूर्णपणे संपादनक्षम (Fully Unlocked & Editable).
  - इनलाइन **`-` / `+` Stepper Buttons**: संख्या सहज ०.५० ने पुढे-मागे करण्यासाठी.
  - **⚡ स्मार्ट ऑटो-फिल (Smart Auto-Fill):** एका क्लिकवर वास्तववादी नैसर्गिक चढ-उतार असलेली १० दिवसांची आकडेवारी (सकाळ: ~३५.०० ते ~४८.५० लि., दुपार: ~३८.०० ते ~४५.०० लि.).
  
- **शुद्ध कृष्ण-धवल अधिकृत पावती (Pure B&W Official Receipt):**
  - बँक व मुद्रणासाठी सर्वोत्तम A4 सिंगल-पेज लेआउट.
  - नॅशनल / को-ऑपरेटिव्ह डेअरी मानकांनुसार शुद्ध काळा व पांढरा (#000000 on #FFFFFF) डिझाइन.
  - ब्राऊझर नेटिव्ह व्हेक्टर प्रिंट व PDF डाउनलोड (`Ctrl + P` / Save as PDF).
  - परिपूर्ण देवनागरी लिपी (Devanagari OpenType Ligatures).

- **द्विभाषिक अंक प्रणाली (Dual Numeral Support):**
  - एका क्लिकवर मराठी (०-९) आणि इंग्रजी (0-9) अंकांमध्ये रूपांतर.
  - मराठी अक्षरी रक्कम स्वयंचलित रूपांतर (उदा. *₹ ४९,२००* -> *एकोणपन्नास हजार दोनशे रुपये फक्त*).

- **इतिहास व बॅकअप (History & Data Export):**
  - LocalStorage मध्ये स्वयंचलित मसुदा साठवणूक (Auto-save Draft).
  - मागील बिले जतन करणे आणि पुन्हा लोड करणे.
  - एक्सेल (CSV) आणि JSON बॅकअप डाउनलोड पर्याय.

## 🛠️ तंत्रज्ञान (Tech Stack)

- **Frontend:** React 18, TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Typography:** Tiro Devanagari Marathi, Noto Sans Devanagari

## 🚀 इन्स्टॉलेशन आणि रन करणे (Setup & Run)

```bash
# १. रेपॉझिटरी क्लोन करा
git clone <repository-url>
cd shivkrupa-dairy-billing

# २. डिपेंडेंसी इन्स्टॉल करा
npm install

# ३. डेव्हलपमेंट सर्व्हर सुरू करा
npm run dev

# ४. प्रॉडक्शन बिल्ड तयार करा
npm run build
```
